# Краткое описание проделанной работы
В рамках задания была проведена работа по анализу и прогнозированию стоимости автомобилей. Работа была разделена на несколько этапов:

## 1. EDA и обработка данных
- Анализ структуры данных
- Поиск и заполнение пропусков медианными значениями
- Удаление дубликатов по признаковым описаниям
- Преобразование типов данных
- Извлечение числовых значений из текстовых полей (mileage, engine, max_power)
- Удаление столбца torque

## 2. Визуализация
- Построение графиков для анализа распределений признаков
- Сравнение распределений в тренировочных и тестовых данных
- Анализ корреляций между признаками

## 3. Моделирование на вещественных признаках
- Обучение линейной регрессии
- Оценка метрик качества модели
- Интерпретация коэффициентов модели

## 4. Добавление категориальных признаков
- Кодирование категориальных переменных
- Повторное обучение модели с включением новых признаков

## 5. Создание интерактивного приложения на Streamlit
- Разработка веб-интерфейса для предсказания стоимости автомобиля
- Интеграция обученной модели в приложение


# Результаты моделирования
#### Модель на вещественных признаках
- R² на тесте: ~0.6–0.65
- Основные признаки: year, km_driven, engine, max_power
#### Модель с категориальными признаками
- R² улучшился до: ~0.7–0.75
- Категории с наибольшим влиянием: fuel, transmission, seller_type

#### Что не удалось сделать и почему
- Столбец torque был удален из-за сложности парсинга и неоднородного формата данных
- Недостаточная предобработка выбросов и ограниченный фичеинжиниринг из-за нехватки времени
